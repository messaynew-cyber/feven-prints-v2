## 🔴 MISTAKES I MADE, AND WHAT THEY COST

These are written down so they are not repeated.

### 1. Shipped a blank page to a live client site — TWICE

The holiday engine worked in isolation. It killed the whole page.

```
line 40:  applyLang(current);          ← calls renderHoliday
line 47:  var HOLIDAY_COPY = { ... };  ← declared AFTER the call
```

`var` hoists as `undefined`; the first property read threw; that one throw
killed every line after it — including the `IntersectionObserver` that reveals
the page. `.reveal { opacity: 0 }` meant the site did not look *broken*. It
looked **empty**. The Architect caught it from a screenshot.

**Root cause: I shipped on `node --check`, which only proves a file parses.**
Green syntax is not green behaviour. `domtest.js` / `livetest.js` now exist and
**must** be run before every push.

This same class of bug bit me **three times** before I fixed the cause rather
than the instance — `main.js` now defines everything in dependency order with
`applyLang` last.

### 2. Wrote a test that was wrong, then chased a bug that did not exist

My delivery test built dates with `toISOString()`, which converts to **UTC**.
Addis is **UTC+3**, so before 03:00 local it returns **yesterday**. A valid
same-day order looked like a past date. The app was right; my test was feeding
it the wrong day. Three tool calls wasted.

**Rule: build test dates in local time.**

### 3. Introduced a pricing conflict in T-02 and only found it in T-21

Mugs had pack pricing in `sizes` (1/2/4 at 350/650/1200) **and** a percentage
ladder from the `gifts` tier. So "2 mugs" cost **650** one way and **644** the
other. Two prices for one order.

**Rule: one discount mechanism per product family.** If a product already
prices by quantity, do not stack a percentage on top.

### 4. A claim in my own audit was wrong

I said dark-mode `theme-color` sync was missing. It already existed at
`main.js:254`. Corrected in `STATE.md` so the mistake is not inherited.

## 🔍 THINGS LEARNED ABOUT THE PLATFORM

**Deleting a file from the repo does not remove it from Cloudflare.**
`fonts/noto-ethiopic.woff2` was deleted, every reference removed, gone from
`git ls-files` — and still served at HTTP 200, 198,324 bytes, byte-identical
to git history. Diagnosed in three steps: fresh deploy URL → 404 (deploy is
fine); custom domain → 200; custom domain **with a cache-buster** → 404. So it
was purely the edge cache. Fixed with a `_redirects` 410 tombstone.

**`pip install brotli` needs compiling — a hard no on this device.**
`apt-get install woff2` gives the reference tools; `woff2_decompress` →
`fontTools.subset` → `woff2_compress` works without compiling anything.

**`run_python` and `linux_run` have different filesystems.** The repo is only
reachable from `linux_run`.
